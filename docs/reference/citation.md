# Publications and citation

Cite the EvoMO paper when using the library in research, and the relevant algorithm
paper when your work builds on that contribution.

## EvoMO and tensorization

Zhenyu Liang, Hao Li, Naiwei Yu, Kebin Sun, and Ran Cheng.
**Bridging Evolutionary Multiobjective Optimization and GPU Acceleration via Tensorization.**
*IEEE Transactions on Evolutionary Computation*, 2025.
[Published paper](https://doi.org/10.1109/TEVC.2025.3555605) ·
[arXiv](https://arxiv.org/abs/2503.20286).

Hao Li, Zhenyu Liang, and Ran Cheng.

[Published paper](https://doi.org/10.1109/CEC65147.2025.11043108) ·
